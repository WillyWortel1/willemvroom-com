A daily routine

  1. 5 min, read: skim your feed and save 2–3 posts worth replying to.
  2. 15 min, reply: write 3–5 thoughtful replies in Reply mode or the Reply App.
  3. 15 min, write: one post in the Toolkit App: hook → body → algorithm check.
  4. If it’s useful: end with a share question.
  5. First hours after posting: answer the replies you get (see Timing).
  6. Weekly: look at which posts got follows, mutes or “not interested” and adjust (see Negative signals).

This routine is my suggestion, not something from X’s code.

FAQ

Is this the official X algorithm?

These weights are the defaults in X’s open-source repo xai-org/x-algorithm (param.rs at commit 5ed7963). X can override defaults in production; that part isn’t public uncertain.

Does one report cancel 234 likes?

No. Weights multiply predicted probabilities, not counts. X’s own README says so. See X Algorithm.

Are links penalized?

Open link has a positive weight (+0.2) and no link penalty appears in param.rs. Effects elsewhere aren’t ruled out uncertain.

Should I end every post with “Who needs this?”

Only useful posts. Asking on a weak post invites “not interested” instead. See Shares on X.

Do the apps send my data anywhere?

No. The apps run in your browser and save to localStorage. Posting opens X’s own compose window.
